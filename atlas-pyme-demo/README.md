# Atlas PyME — Demo comercial

MVP estático para validar demanda antes de contratar infraestructura.

## Incluye
- Dashboard con ventas, utilidad e inventario.
- Inventario y alta de productos.
- Venta rápida con descuento de stock.
- Historial de ventas.
- Persistencia local en `localStorage`.
- Datos demo; no utiliza Supabase ni modifica Donatello.

## Objetivo
Mostrar el producto a prospectos, validar disposición de pago y cerrar el primer cliente antes de invertir en backend multi-tenant.

## Ejecutar
Abrir `index.html` con un servidor estático. No requiere variables de entorno ni backend.
