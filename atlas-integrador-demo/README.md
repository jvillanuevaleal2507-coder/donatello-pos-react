# Atlas Integrador Demo V1

Prototipo estático para validar navegación, jerarquía visual y prioridades antes de conectar backend.

## Incluye
- Dashboard ejecutivo
- Bandeja de proyectos
- Ficha de proyecto con rentabilidad y seguimiento
- Inventario
- Compras
- Mano de obra
- Vista operativa de Almacén
- Navegación preparada para Clientes, Cotizaciones, Reportes y Configuración
- Selector demo de rol

## No incluye todavía
- Persistencia real
- Supabase
- autenticación/RBAC real
- flujo completo de cotización
- formularios funcionales de recepción/salida
- facturación/finanzas
- IA

## Ejecución local
Abrir `index.html` directamente o servir la carpeta con cualquier servidor estático.

## Decisión de arquitectura
Este prototipo vive en la rama `atlas-integrador-v1`, separada de producción y del demo Atlas PyME. El objetivo es validar producto/UX antes de crear la base de datos definitiva.
